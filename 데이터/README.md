# 데이터 형식

생성기는 이 폴더의 파일 두 개만 읽는다. 둘 다 "브라우저용 JS" 꼴이라 사이트에도 그대로 올릴 수 있다.

## 1. schools-data.js (필수) — 학교 목록
전국 초·중·고 학교 목록이 들어 있다(공공데이터 학교 기본정보에서 만든 것). 그대로 써도 되고, 특정 지역만 남겨도 된다.

```js
window.SCHOOLS = [
  {n:"동래고등학교", r:"부산 동래구", t:"고"},
  {n:"하계중학교",   r:"서울 노원구", t:"중"},
  {n:"내성초등학교", r:"부산 동래구", t:"초"},
  ...
];
```
- `n` 정식 명칭(…초등학교/…중학교/…고등학교 로 끝나야 한다. 분교·가칭은 자동 제외)
- `r` "시도 시군구" (시도는 서울·경기·인천·부산·대구·광주·대전·울산·세종·강원·충북·충남·전북·전남·경북·경남·제주 중 하나. 구가 있는 시는 "경기 고양 덕양구"처럼 세 토막)
- `t` 초 / 중 / 고
- 약칭(동래고·하계중·내성초)은 생성기가 자동으로 만든다(공용/lib.js shortName). 같은 약칭이 둘 이상이면 파일명이 `약칭-지역` 이 된다.

## 2. teachers-data.js (선택) — 선생님 목록
없으면 선생님 0명으로 만든다(선생님 메뉴·카드가 비어 보이니 실제 운영 전에는 채우는 것이 좋다).

```js
window.TEACHERS=[
  {"i":"T0001","n":"박O옥","g":"여","c":"방문","s":["영어"],"gr":["초2~고3"],"sd":"경북","r":"경북 포항 남구|경북 포항 북구","tag":"포항 20년 경력 영어 방문과외","k":0},
  {"i":"T0002","n":"김O수","g":"남","c":"화상","s":["수학","과학"],"gr":["중1~고3"],"sd":"","r":"","tag":"개념부터 잡는 수학·과학 화상수업","k":0}
];
```
- `i` 고유 id(파일명 t/{id}.html 이 된다) · `n` 이름(가운데 글자 가림 권장) · `g` 성별
- `c` "방문" / "화상" / "방문+화상"
- `s` 과목 배열(국어·영어·수학·사회·과학·한국사·물리·화학·생물·코딩 …)
- `gr` 학년 범위 배열("초1~고3" 꼴이면 학교급 매칭에 쓰인다)
- `r` 방문 가능 지역, "시도 시군구" 를 `|` 로 이어 쓴다(화상 전용이면 빈칸). 학교 페이지의 "방문 가능 선생님"은 이 값과 학교의 `r` 를 맞춰 고른다.
- `tag` 한 줄 소개 · `k` 0

### 선택: t/{id}.html — 선생님 소개글
`데이터/t/T0001.html` 처럼 두면 안의 첫 `<h2>`(제목 한 줄)와 `class="td-intro"` 문단(소개)을 읽어 선생님 상세 페이지에 넣는다. 없어도 된다.
